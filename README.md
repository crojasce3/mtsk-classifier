# Multilingual and explainable classification of MTSK research

Code, results and materials for the article

> Rojas Celis, C., Elorreaga Rodríguez, L. M., & Hortúa, H. J. *Multilingual and Explainable Classification of Research on Mathematics Teacher's Specialised Knowledge (MTSK)*. Manuscript submitted to *PLOS ONE*.

The study classifies research grounded in the Mathematics Teacher's Specialised Knowledge (MTSK) model into the five thematic areas of the Ibero-American MTSK Network (RedMTSK), using an expert-labelled corpus of 278 documents in Spanish, English and Portuguese. It compares three readers of this literature:

- an explainable classifier based on a fine-tuned `intfloat/multilingual-e5-large` encoder, analysed with SHAP;
- a prompted large language model (DeepSeek API);
- an independent expert who classified a stratified sample of 100 documents.

## Main results

| Reader | Evaluation | Macro-F1 | Accuracy |
|---|---|---|---|
| multilingual-e5-large (128 tokens) | 5-fold CV, 278 documents | 0.732 (95% CI 0.677–0.782) | 0.763 |
| multilingual-e5-large (256 tokens) | 5-fold CV, 278 documents | 0.755 | — |
| MiniLM-L12-v2 | 5-fold CV, 278 documents | 0.663 | 0.665 |
| TF-IDF + logistic regression | 5-fold CV, 278 documents | 0.656 | 0.665 |
| XLM-RoBERTa base | 5-fold CV, 278 documents | 0.507 | 0.496 |
| Prompted LLM (DeepSeek) | single pass, 278 documents | 0.835 | 0.824 |
| Independent expert | sample of 100 documents | 0.849 | 0.850 |

See the article for the full analysis, including the interpretation of errors, the comparison between readers and the limitations of each evaluation.

```

  03_llm_classification_deepseek.ipynb  classification of the corpus with the DeepSeek API

results/                             predictions and annotations needed to reproduce every number
```

## Data availability

The texts of the documents cannot be redistributed because of the original publishers' copyright. `data/MTSK_corpus_metadata_278.csv` lists, for each of the 278 documents, its title, DOI (where available), bibliographic reference, thematic area, language, related-version group and cross-validation fold. With that list, the corpus can be reconstructed from the original sources. Each release of this repository is archived on Zenodo with a persistent DOI.

`results/labels.csv` contains, for each document (identified by its row in the curated corpus and its original ID), the thematic area, the language, the related-version group and the cross-validation fold.

## Reproducing the results

The analysis scripts work only with the files in `results/` and reproduce all the figures reported in the article without access to the texts or to a GPU:

```bash
pip install -r requirements.txt
python scripts/cv_analysis.py
python scripts/comparison_analysis.py
python scripts/shap_word_level.py --shap path/to/shap_values.pkl   # requires the SHAP values, see below
```

To rerun the models from scratch, reconstruct the corpus as an Excel file with the columns `Título`, `Resumen (texto literal)`, `Palabras clave (texto literal)`, `Clasificacion tematica`, `Idioma` and `Grupo`, in the row order of `results/labels.csv`, and run the notebooks in order (Google Colab or Kaggle with a GPU; the LLM notebook needs a DeepSeek API key stored as a Colab secret named `DEEPSEEK_API_KEY`). The cross-validation partition is deterministic (`StratifiedGroupKFold` without shuffling), so `folds.json` will be identical. The SHAP values (`shap_values.pkl`) are produced by notebook 02 and are not included because they contain the tokenised text of the abstracts.

Two runs of the cross-validation protocol on the same GPU type reproduced the predictions exactly. Different hardware may introduce small numerical differences. The 256-token variant proved less stable across runs, as reported in the article.
